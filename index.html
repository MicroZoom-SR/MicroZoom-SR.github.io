How It Works

1. Data Capture

We capture a set of close-up macro photographs of an object alongside a single full-view reference image. A connecting video is used to register each close-up to the corresponding region in the full image, producing per-pixel scale and alignment information.

2. Per-Instance Fine-Tuning

We fine-tune lightweight LoRA adapters on both the Flux.1-dev transformer and its ControlNet upscaler, using the close-up/full-image pairs. Multi-texture label maps guide the model to synthesize each material region with the correct high-frequency detail.

3. Gigapixel Inference

A sliding-window multi-diffusion pipeline processes the full image in overlapping tiles. Tile stride decreases at early denoising steps for global coherence and increases at later steps for detail; Gaussian blending removes seam artifacts at boundaries.
